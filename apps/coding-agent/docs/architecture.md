# Architecture

**English** · [简体中文](zh-CN/architecture.md)

Built on [`@ji.dev/llm`](../../../packages/llm), with tools from [`plugin-files`](../../../plugins/files), [`plugin-shell`](../../../plugins/shell) and [`plugin-choices`](../../../plugins/choices). `src/` holds only the entry, [`main.ts`](../src/main.ts); the rest is in a folder per layer. `agent/` and `plugins/` know nothing of the terminal.

| File                                               | What it does                                                                                                                                                                           |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`agent/`**                                       | **The model and the conversation**                                                                                                                                                     |
| [`agent.ts`](../src/agent/agent.ts)                | Creates the agent: model, thinking level, system prompt, plugins                                                                                                                       |
| [`conversation.ts`](../src/agent/conversation.ts)  | Sending and steering; a reply that does not finish goes back to before it was sent, and gives back its messages                                                                        |
| **`plugins/`**                                     | **The coding agent's own**                                                                                                                                                             |
| [`tools.ts`](../src/plugins/tools.ts)              | Two small tools, calc and now                                                                                                                                                          |
| [`permissions.ts`](../src/plugins/permissions.ts)  | Which calls wait for a yes: ask/auto modes, the shortcuts in a question, the commands and folders a yes allowed. Policy only, not how it is shown                                      |
| **`ui/screen/`**                                   | **The whole screen**                                                                                                                                                                   |
| [`screen.ts`](../src/ui/screen/screen.ts)          | The three-part layout. What goes to stdout is written to an [`@xterm/headless`](https://github.com/xtermjs/xterm.js) terminal, and one screenful of it is drawn at the scroll position |
| [`cells.ts`](../src/ui/screen/cells.ts)            | Turns a row of that terminal, colors and bold included, back into ANSI text                                                                                                            |
| [`bars.ts`](../src/ui/screen/bars.ts)              | What the bars show: the top bar, the usage line, the status and the input line. Pure functions                                                                                         |
| [`status.ts`](../src/ui/screen/status.ts)          | The status in the bottom bar: what is going on, and for how long                                                                                                                       |
| [`live.ts`](../src/ui/screen/live.ts)              | The rows at the end of the conversation that change in place: a table not yet ended, a call being written or run. Other output goes above them; they step aside for a question         |
| [`usage.ts`](../src/ui/screen/usage.ts)            | Adds up the session's usage                                                                                                                                                            |
| [`editing.ts`](../src/ui/screen/editing.ts)        | The input line's state: a pure `edit(state, key)`, apart from drawing                                                                                                                  |
| **`ui/reply/`**                                    | **A reply**                                                                                                                                                                            |
| [`render.ts`](../src/ui/reply/render.ts)           | Turns a run's events into rows in the two views, and into the status                                                                                                                   |
| [`gutter.ts`](../src/ui/reply/gutter.ts)           | Writes the streaming reply beside clack's rail: text through `Markdown`, thinking dim as it is                                                                                         |
| [`calls.ts`](../src/ui/reply/calls.ts)             | A call and its result in the two views, each row cut to the display width; a call being written or run, and its last lines of output                                                   |
| **`ui/markdown/`**                                 | **The reply's Markdown, drawn as it streams**                                                                                                                                          |
| [`markdown.ts`](../src/ui/markdown/markdown.ts)    | The entry: decides only which element a line belongs to (text, code block, table); each handles its own lines                                                                          |
| [`line.ts`](../src/ui/markdown/line.ts)            | Headings, lists (nested, tasks), quotes, rules: the prefix is set once the start of the line tells what it is, the rest goes out word by word                                          |
| [`inline.ts`](../src/ui/markdown/inline.ts)        | Bold, italic, strikethrough, inline code, links: styled once the marker closes, written as is if it never does                                                                         |
| [`code.ts`](../src/ui/markdown/code.ts)            | Code blocks, in color a line at a time                                                                                                                                                 |
| [`table.ts`](../src/ui/markdown/table.ts)          | Tables: drawn as a grid to the terminal's width once they end; narrows columns and wraps cells when too wide                                                                           |
| [`flow.ts`](../src/ui/markdown/flow.ts)            | Wraps by word, each row with its list or quote prefix                                                                                                                                  |
| **`ui/questions/`**                                | **Approvals and questions**                                                                                                                                                            |
| [`answering.ts`](../src/ui/questions/answering.ts) | Puts a question to the person: the approval's title, mode and shortcuts; draws it again when the mode switches                                                                         |
| [`diff.ts`](../src/ui/questions/diff.ts)           | The diff in an approval: colored by the file's language, the changed parts on a deeper background                                                                                      |
| **`ui/paint/`**                                    | **Painting they all share**                                                                                                                                                            |
| [`text.ts`](../src/ui/paint/text.ts)               | Cutting, tailing and wrapping by display width; how key hints and numbers are written                                                                                                  |
| [`highlight.ts`](../src/ui/paint/highlight.ts)     | Colors code with [shiki](https://shiki.style), line by line with the grammar's state, and can put a background under part of a line                                                    |

To the program, stdout is the conversation between the bars: it is written to a headless terminal whose `columns` and `rows` are the conversation's size, so [clack](https://bomb.sh/docs/clack/basics/getting-started/)'s output and questions work unchanged. The brief and the full view are a headless terminal each, both written to, so switching views needs no replay.
