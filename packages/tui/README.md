# @ji.dev/tui

**English** · [简体中文](README.zh-CN.md)

The parts of a full-screen terminal chat, none of them knowing what is said in it. [`apps/coding-agent`](../../apps/coding-agent) is built on it: it decides what the bars say and how a reply reads, and leaves the drawing here.

```ts
import { createRailRows, Markdown, Screen, widthBesideRail } from '@ji.dev/tui'

const screen = new Screen(columns => ({
  top: ['', ' my app', '─'.repeat(columns - 1)],
  bottom: ['', ' › '],
}))
screen.start()
const markdown = new Markdown(createRailRows(process.stdout, '│'), widthBesideRail)
await markdown.write('# Hello\n\nSome **bold** text\n')
markdown.end()
```

| File                                      | What it does                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`screen/`**                             | **The whole screen**                                                                                                                                                                                                                                                                                                     |
| [`screen.ts`](src/screen/screen.ts)       | The alternate screen in three parts: the caller's bars on top and at the bottom, and between them everything written to stdout, kept by an [`@xterm/headless`](https://github.com/xtermjs/xterm.js) terminal and drawn a window at a time. The wheel and PgUp/PgDn scroll it; the terminal is given back on stop or exit |
| [`cells.ts`](src/screen/cells.ts)         | Turns a row of that terminal, colors and bold included, back into ANSI text                                                                                                                                                                                                                                              |
| [`live.ts`](src/screen/live.ts)           | Rows at the end of the content that change in place; other output goes above them, and they step aside for a prompt                                                                                                                                                                                                      |
| [`status.ts`](src/status.ts)              | A status that spins and counts the seconds                                                                                                                                                                                                                                                                               |
| [`editing.ts`](src/editing.ts)            | The input line: a pure `applyKey(state, key)`, and `renderInputLine` to draw it scrolled to the cursor                                                                                                                                                                                                                   |
| **`markdown/`**                           | **Markdown as it streams in**                                                                                                                                                                                                                                                                                            |
| [`markdown.ts`](src/markdown/markdown.ts) | The entry: decides only which element a line belongs to (text, code block, table); each handles its own lines                                                                                                                                                                                                            |
| [`line.ts`](src/markdown/line.ts)         | Headings, lists (nested, tasks), quotes, rules: the prefix is set once the start of the line tells what it is, the rest goes out word by word                                                                                                                                                                            |
| [`inline.ts`](src/markdown/inline.ts)     | Bold, italic, strikethrough, inline code, links: styled once the marker closes, written as is if it never does                                                                                                                                                                                                           |
| [`code.ts`](src/markdown/code.ts)         | Code blocks, in color a line at a time                                                                                                                                                                                                                                                                                   |
| [`table.ts`](src/markdown/table.ts)       | Tables: drawn as a grid to the width once they end; narrows columns and wraps cells when too wide                                                                                                                                                                                                                        |
| [`flow.ts`](src/markdown/flow.ts)         | Wraps by word, each row with its list or quote prefix                                                                                                                                                                                                                                                                    |
| [`plain.ts`](src/markdown/plain.ts)       | Plain text the same way, in the formats given                                                                                                                                                                                                                                                                            |
| **Painting**                              |                                                                                                                                                                                                                                                                                                                          |
| [`rail.ts`](src/rail.ts)                  | clack's rail, and rows written beside it                                                                                                                                                                                                                                                                                 |
| [`highlight.ts`](src/highlight.ts)        | Colors code with [shiki](https://shiki.style), line by line with the grammar's state, and can put a background under part of a line                                                                                                                                                                                      |
| [`diff.ts`](src/diff.ts)                  | A diff in the colors of its file, the changed parts on a deeper background                                                                                                                                                                                                                                               |
| [`output.ts`](src/output.ts)              | The tail of a running command's output: how many lines, and the last ones with text                                                                                                                                                                                                                                      |
| [`layout.ts`](src/layout.ts)              | A line fitted to its width: the first version that fits, a path shortened from its start, a rule with labels; a help screen of keys                                                                                                                                                                                      |
| [`text.ts`](src/text.ts)                  | Cutting, tailing and wrapping by display width; dim text, key hints and counts                                                                                                                                                                                                                                           |

To the program, stdout is the content between the bars: it is written to a headless terminal whose `columns` and `rows` are the content's size, so [clack](https://bomb.sh/docs/clack/basics/getting-started/)'s output and prompts work unchanged. The brief and the full view are a headless terminal each, both written to, so switching views needs no replay. The screen takes over the process's stdout, so there is one at a time.
